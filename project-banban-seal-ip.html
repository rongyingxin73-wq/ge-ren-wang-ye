品牌 IP

斑斑 BANBAN 海豹 · 品牌 IP 形象设计

一只圆滚滚、爱打盹的小海豹。围绕主形象延展了表情包、三视图、不同造型、周边衍生品与扁平插画海报，搭起一整套适合社交媒体与品牌传播的 IP 资产。

MODULE 01 / 主形象展示

IP 主形象

5 张主形象设定，覆盖基础造型、表情、动作与场景延展，作为整套 IP 视觉的核心。

MODULE 02 / 表情包

表情包合集

一组可日常使用的斑斑表情包，覆盖开心、撒娇、emo、打盹等高频情绪——点击查看完整长图。

斑斑海豹 · 表情包

MODULE 03 / 造型与设定

三视图 & 造型延展

标准三视图确定基础比例与五官造型；不同造型展示斑斑在不同情绪与场景下的延展能力。

MODULE 04 / 周边延展

周边衍生品

围绕主形象设计的实体周边，覆盖毛绒玩具、徽章、贴纸等品类，方便 IP 在不同场景落地。

MODULE 05 / 扁平插画海报

扁平插画海报

用于社交媒体与品牌传播的扁平插画海报延展，强化斑斑海豹在不同主题下的视觉表达。

MODULE 06 / 线下物料与活动延展

夏日乐园物料

围绕 Sunnyboo 海豹夏日乐园主题延展的线下物料与活动海报，覆盖工作牌、门头、市集摊位及横竖版活动宣传，强化 IP 在商业场景中的落地能力。

MODULE 07 / 自我介绍视频

BANBAN 自我介绍

一段可爱的自我介绍小动画，让斑斑海豹的品牌性格更生动地传递出来。
